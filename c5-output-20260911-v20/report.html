目前工具可以做什麼

目前工具可以做什麼：

  • 自動找出和正常紀錄差異較大的時間區段。
  • 告訴工程師應該先回 LeCroy GUI 查看哪裡。
  • 不需要事先提供已知故障時間。

分析方式：

  • PASS trace 用來建立正常紀錄參考值。
  • PASS / FAIL 各自以時間區段比較，不強行對齊兩份 trace 的時間。
  • LFPS 原始值保留數字，不自行猜測 enum 名稱。
  • 工程師標記的區域只用於事後驗證，不是分析輸入。

目前還不能做什麼：

  • 判定真正故障原因。
  • 判斷故障嚴重程度。
  • 自動判定產品 PASS / FAIL。
