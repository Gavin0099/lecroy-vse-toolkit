# r7.2 大檔防護試用候選版

本頁保留 r7.2 的歷史行為。r7.3 已加入磁碟索引路線，超過 20,000 TLP 會自動選路，請優先閱讀 [大量交易解析說明](pcie-dense-analysis-usage.md)。下列 20,000 TLP／8 MiB Probe 限制描述的是舊路線，不能用來解釋 r7.3 的全部行為。

這是資源防護與分頁改善版，**尚未驗證 1 GiB 以上原生 PCIe trace 容量**。目前原生開檔驗證案例約 120.5 MiB、3,457,139 Packet、704 TLP；不能由 Packet 總數推論高密度或 2 GiB 支援。

解壓完整資料夾，執行 `USBTraceTriage.exe`。保留 `runtime`、`tools`、`scripts`、`knowledge` 及 `.agents`；不需另裝 Python。仍需本機 LeCroy USB Suite／PETracer，原生版本相容性沿用原有驗證範圍。

## 新的可見行為

- 匯入時顯示階段與等待秒數。原生呼叫沒有可信進度時不顯示虛構百分比。
- 所有轉換只在工作副本執行。取消會先等待安全呼叫邊界；停止 worker 不表示 PETracer 已停止。
- Flow 第一屏保留最多三個檢查目標；勾選「包含較早流程」後用上一頁／下一頁，每頁最多 20 項。候選也支援分頁。
- 原始來源、完整模型、HTML／Markdown 和所有保留證據仍在工作資料夾；畫面頁面不代表全部證據。
- 格式轉換成功且清理確認後，工具可以保存轉換副本。下一次匯入會核對來源、原生版本、程式與 Type Library hash、轉換副本 hash，再建立新的工作副本。**六個 Probe、Flow、Knowledge 與工程情境均重新處理**；沒有完整分析結果快取，也未承諾 15 秒完成。
- 快取位於工作輸出根目錄的上一層 `pcie-conversion-cache`。上限 6 GiB，滿時停止新增，不自動刪除可能正使用的項目。關閉工具並確認沒有使用中的原生工作後，可以自行移除這個快取資料夾；原始 trace 不在裡面。

## 安全限制與恢復

以下是本機工程政策，不是 PCIe 協定上限或已驗證容量：

| 項目 | 預設 |
|---|---:|
| 磁碟保留空間 | 2 GiB；另預留工作／轉換副本需求 |
| 單 callback | 1 MiB UTF-8 |
| 單 Probe 文字 | 8 MiB |
| TLP 數量 | 20,000 |
| 完整桌面模型 | 8 MiB UTF-8 |
| UI 頁面 | 1 MiB UTF-8，最多 20 項 |
| 工具 worker／controller private bytes | 各 512 MiB，依監測可觀測範圍 |
| PETracer private bytes | 4 GiB |
| 全擷取等待上限 | 7,200 秒 |
| 開檔／轉換階段 | 1,200 秒 |
| 每個 Probe | 1,800 秒 |
| 其他階段／離線模型 | 900 秒 |

超限時保留 `.partial`、`worker.json`、`analysis.log`、`resources.jsonl` 或 `model-worker.log`，不產生完成候選。這類受控拒絕**不是該容量分析通過**。目前大量交易解析仍有待改造的全量資料結構。

記憶體監測不能保證任何 Windows／原生外掛都不會 OOM。若原生呼叫被監測器中止等待、或工作清理未確認，工具會拒絕啟動下一個衝突工作；請保留日誌，核對 PETracer 狀態後重新啟動工具。不要只因 UI 顯示「已取消要求」就刪除正在使用的副本。

若完整分析已完成但分頁無法載入，使用工作資料夾中的完整報告；重新匯入會建立新工作。若磁碟不足，選擇空間足夠的位置後重試，不要刪除原始來源。

本版不自動切割 `.pex`。官方 Save 範圍實驗顯示子檔重新編號，邊界 Idle／Time Delta 與完整檔可能不同；尚未核對跨段交易／LTSSM 等價性。全檔 Coverage、實體 Link 配對與裝置初始化仍保留既有 UNKNOWN。
