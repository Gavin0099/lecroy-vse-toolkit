結論為 **APPROVE（離線契約範圍）**。本次 review 未發現阻擋下一片準備的 P0／P1 問題；不代表 PCIe／USB 規格判定、真實 trace 或 runtime coverage 已資格化。

審查範圍為兩份 S01 schema、`tools/s01_contract.py`、fixtures／手寫預期、CLI 與 legacy compatibility。42 項離線 tests 本輪重跑通過，包含既有 64 組手寫 readiness 預期。沒有改 S01 程式、schema 或原測試。

| 查核重點 | 工程意義與結果 |
| --- | --- |
| Capability／observation 分軸 | API supported 與 availability 不混用；positive event 在 partial capture 可保留；unknown 不會自動變成零事件 |
| 負面觀察 | selected、retained、extraction、filter 與 bounded range 任一缺少，均拒絕 `not_observed_in_coverage` |
| 來源角色與 trace 綁定 | document 不當 recorded availability；known facts／observations 需同 trace；metadata-only 文件不能建立 API supported |
| Eligibility | 重算 profile 條件並拒絕被竄改 assessment；unknown／missing／not_applicable 保留逐項原因；qualification 固定 NOT_EVALUATED |
| Legacy／historical claims | explicit formats；原始 bytes 與 decoded original 保留；不猜 mode／epoch／filters、不重評原 PASS |
| 隱藏 verdict／拒絕路徑 | closed object 禁止額外 verdict；非法型別、空 refs、wrong version、非有限 JSON 數字與重複 ID 被拒絕 |
| 實作隔離 | 無 extraction／scoring pipeline imports；CLI 不追 evidence locator，W1–W5 與另一 checkout 不變 |

限制仍是 schema/semantic consistency，而不是內容真實性認證；自訂 walker 只支援 bundled vocabulary。Trace profile 的充分性與 evidence 的人工核驗不由 S01 自動完成。這些已明列的 claim boundary 不是新缺陷，未因此擴大歷史 PASS。

依最新使用者指令啟動 **U01 的離線準備**，不開第二片。完整 runner、七種 selection 與測試見 [U01](u01-selection-coverage.md)。前輪明確禁止的 LeCroy／COM runtime 是否解除，已呈現具體唯讀副本計畫供確認；沒有收到回覆前不執行。
