# USB knowledge source use

All cards are repository-authored engineering notes and links. No external
source code or complete specification is included. GPL headers and TCPM are
field/implementation references only; no GPL code is incorporated. Microsoft
guidance and Linux documentation do not establish cross-platform behavior.
USB-IF source terms and applicable adopter agreements still govern original
documents. The reviewed USB3 test PDF permits internal reproduction only;
it is not distributed. Catalog availability grants no redistribution rights.
Original-byte versus authored-review hashes are explicitly labelled in
sources.json and source-review.md. Runtime validation verifies the local pack,
not a fresh network check, certification, or legal permission for spec reuse.
